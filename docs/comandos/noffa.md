# `/noffa`

A **joke**. Puts rainbow emojis between the words. Accepts text or a reply to a message (the typed text and the
replied message's text are joined). With neither, it shows the usage.

```text
/noffa bom dia grupo
→ bom 🌈 dia 🏳️‍🌈 grupo

  🤡 Just a joke from /noffa.
```

The emojis cycle through 🌈 🏳️‍🌈 🏳️‍⚧️ 🧡 💛 💚 💙 💜, one per space. If the text starts with `/`, the reply
gets a 🌈 in front, so it never looks like a command.
