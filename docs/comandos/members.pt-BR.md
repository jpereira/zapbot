# `/members` (`/listageral`, `/list`) · admin

Role `admin`: só você e os admins extras. O dono libera a uma pessoa ou grupo com
`/bot +u +cmd /members` ([Delegando](index.md#delegando-um-comando-admin)).

Só em grupos (fora deles responde `Apenas utilizado dentro de grupos.`): lista os membros, um por
linha como `número - nome`, com 👑 dono e ⭐ admin. Um número que o WhatsApp esconde aparece como
`(número oculto)`; um contato sem nome, como `Desconhecido`.

```text
/members
/list           → o mesmo, pelo alias
```
