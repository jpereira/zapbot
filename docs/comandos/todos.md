# `/todos` (`/todes`) · admin

Role `admin`: só você e os admins extras. O dono libera a uma pessoa ou grupo com
`/bot +u +cmd /todos` ([Delegando](index.md#delegando-um-comando-admin)).

Só em grupos. Responde à sua mensagem mencionando todos os participantes (exceto você).

```text
/todos
/todes          → o mesmo, pelo alias
```
