# `/noffa` (`/🌈`, `/🏳️‍🌈`)

Coloca emojis de arco-íris entre as palavras. Aceita texto ou reply numa mensagem (o texto digitado
e o da mensagem respondida são juntados). Sem nenhum dos dois, mostra o uso.

```text
/noffa bom dia grupo
→ bom 🌈 dia 🏳️‍🌈 grupo
```

Os emojis se alternam entre 🌈 🏳️‍🌈 🏳️‍⚧️ 🧡 💛 💚 💙 💜, um por espaço. Se o texto começar com `/`, a
resposta ganha um 🌈 na frente, para nunca parecer um comando.
