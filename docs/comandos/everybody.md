# `/everybody` · admin

Role `admin`: only you and the extra admins. The owner can grant it to a person or group with
`/bot +u +cmd /everybody` ([Delegating](index.md#delegating-an-admin-command)).

Groups only (anywhere else it replies `Only usable inside groups.`). Replies to your message
mentioning all the participants (except you); with nobody else in the group it does nothing.

```text
/everybody
```
