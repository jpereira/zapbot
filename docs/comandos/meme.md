# `/meme`

Template de meme aleatório do [imgflip](https://imgflip.com/), opcionalmente
filtrado pelo nome (`/meme drake`). A imagem vem com o nome do template na
legenda.

```
/meme           → um template qualquer
/meme drake     → um com "drake" no nome
```

```
/meme drake
[imagem do template]
🖼️ Drake Hotline Bling
```

Sem nenhum template com o nome pedido, o bot responde `❌ Nenhum meme com
"<busca>".`; se o imgflip não responder, `❌ Não consegui buscar um meme agora.`
